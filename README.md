# clipper.md

Telegram bot for Obsidian that converts forwarded messages into Markdown notes.
Like [Obsidian Web Clipper](https://obsidian.md/clipper), but for Telegram.

## Get started

1. Open [@obsidian_clipper_md_bot](https://t.me/obsidian_clipper_md_bot) in Telegram.
2. Forward a message to it.
3. Tap the link the bot sends back to add the note to your vault.

No downloads. No signup.

More at [clipper.md](https://clipper.md).
