# obsi

Obsi is a Telegram bot that allows you to clip posts from Telegram to [Obsidian](https://obsidian.md/).

Like [Obsidian Web Clipper](https://obsidian.md/clipper), but for Telegram.

## Get Started

Head over to [@obsiapp_bot](https://t.me/obsiapp_bot) to start using the bot
and try out clipping some posts.

## About

This bot is made by the community 💜 and not affiliated with Obsidian.
